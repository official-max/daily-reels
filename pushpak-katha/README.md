# Pushpak Katha: Ramayan

Poori Valmiki Ramayan, adhyay-dar-adhyay, animated Hindi Shorts. Channel: https://www.youtube.com/@PushpakKatha

| Folder | Kya hai |
|---|---|
| `plan/ramayan.json` | 732 bhaag, kahani ke kram mein (661 adhyay, 10 khand) |
| `plan/channel.json` | shuru ki tareekh, roz kitne bhaag |
| `scripts/001.md` ... | har bhaag ki script aur uska adhyay |
| `engine/` | `lab.py` awaaz, captions, encoding; `rig.py` action kirdaar; `audio.py` sangeet; `hanuman.py` udaharan video |
| `state/` | kahan tak aaya (automatic system ke liye) |
| `brand/` | logo, banner |

## Niyam
- Ek adhyay = ek video. Bada adhyay (1300 shabd se zyada) do bhaag. Lambai 60-90 second, 170 se zyada kabhi nahi.
- Har script se pehle adhyay poora padhna; apne shabdon mein likhna, anuvaad copy nahi.
- Ram, Sita, Lakshman jaise mukhya kirdaar har bhaag mein wahi; jagah, frame, kapde aur baaki kirdaar naye.
- Uttar 76 aur Sita tyag wale bhaag banane se pehle poochhna.
